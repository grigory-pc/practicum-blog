# practicum-blog
Данный проект представляет сервис блога.
Приложение позволяет:
1. Посмотреть ленту превью постов.
2. Сделать фильтрацию постов по тегам.
3. Для отображения ленты доступна пагинация по 10, 20, 50 постов на странице.
4. Добавить/изменить пост.
5. Посмотреть пост из ленты.
6. Добавить/изменить комментарий к посту.
7. Добавить лайк к посту.

Приложение написано на Java.
При разработке приложения использовалась JAVA 21.

--- 
Тесты разработаны на базе JUnit 5 при использовании mockito.

---
Frontend сделан на базе фреймворка vaadin. В рамках текущей версии взаимодействие между сервлетами frontend и backend не поддерживается.
Планируется поддержка после миграции со Spring на SpringBoot
